## RL-LOW-PASS-FILTER-CIRCUIT
This project analyzes the behavior of an RL low-pass filter using MATLAB.

# Project Description
The circuit is designed to study how an RL filter attenuates high-frequency signals while allowing low-frequency components to pass. The analysis focuses on the frequency response and signal behavior at the input and output of the circuit.

# Analysis Performed
- Gain vs frequency analysis
- Phase vs frequency analysis
- Input and output voltage signal comparison

# Tools Used
- MATLAB
